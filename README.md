# Meus Desafios com IA

Este repositório reúne desafios, projetos e experimentos desenvolvidos durante meus estudos sobre Inteligência Artificial e Engenharia de Prompt.

O objetivo é registrar minha evolução na utilização de IA, praticando a criação de instruções claras e bem estruturadas para obter respostas mais precisas e úteis.

Ao longo dos desafios, são explorados conceitos como:

- Criação de prompts claros e objetivos;
- Utilização de contexto e exemplos para obter respostas mais precisas;
- Estruturação de instruções para orientar a IA ao resultado desejado;
- Identificação de informações inconsistentes ou duvidosas geradas pela IA;
- Aplicação prática de Inteligência Artificial para resolver problemas reais;
- Desenvolvimento de soluções utilizando IA Generativa.

## Desafios

### 1. Checklist Inteligente de Medicamentos

O primeiro desafio consiste na construção de um prompt utilizando os princípios básicos da Engenharia de Prompt: intenção clara, contexto e instruções específicas.

A atividade propõe que cada participante desenvolva uma solução própria, aplicando essas etapas para criar um prompt capaz de orientar uma Inteligência Artificial a gerar resultados úteis e alinhados ao objetivo desejado.

Para este desafio, escolhi desenvolver o tema **Checklist Inteligente de Medicamentos**, uma solução pensada para auxiliar pessoas que utilizam vários medicamentos diariamente e precisam organizar horários e doses de forma simples.

Ao longo da atividade, o prompt foi construído passo a passo, demonstrando como uma boa definição de objetivo, contexto e restrições pode ajudar a IA a produzir exatamente o resultado esperado.

**Arquivo:** `desafio-checklist-medicamentos.md`

## Objetivo do Repositório

Este repositório foi criado para documentar meu aprendizado e minha evolução na utilização de Inteligência Artificial, reunindo desafios práticos, experimentos e projetos desenvolvidos ao longo da minha jornada de estudos na área de tecnologia.

Cada desafio representa uma oportunidade de aplicar novos conhecimentos, explorar diferentes formas de interação com IA e desenvolver soluções para problemas reais.
